### 1. 實驗目標(可參考課程投影片寫法)
- 延續 Basic Task 2-1 的 L293D 直流馬達驅動電路，加入可變電阻作為類比輸入。
- 使用可變電阻的旋轉角度同時控制直流馬達的旋轉方向與轉速。
- 了解 Arduino 類比輸入、PWM 輸出與 L293D 馬達驅動之間的控制關係。

### 3. 操作說明與成果
1. **建立馬達驅動電路**：延續 Basic Task 2-1 的接線方式，使用 L293D 作為 Arduino 與 DC 馬達之間的驅動器，並確認 Arduino、L293D 與馬達電源共地。
2. **連接可變電阻**：將可變電阻兩側接至 5V 與 GND，中間輸出腳接至 Arduino 的類比輸入腳位，利用 `analogRead()` 讀取旋鈕位置。
3. **設定旋轉方向**：將可變電阻的中間位置設定為停止區域；旋鈕往一側轉動時，透過 L293D 的兩個輸入腳控制馬達逆時針旋轉；往另一側轉動時則控制馬達順時針旋轉。
4. **設定旋轉速度**：依照可變電阻讀值與中心位置的距離調整 PWM 輸出。旋鈕越偏離中心位置，PWM 輸出越大，馬達轉速越快；接近中心位置時馬達速度降低並停止。
5. **實驗成果**：實際轉動可變電阻後，可觀察到旋鈕往左時馬達逆時針轉速逐漸增加，旋鈕位於中央時馬達停止，旋鈕往右時馬達順時針轉速逐漸增加，成功以單一可變電阻同時控制馬達方向與速度。
