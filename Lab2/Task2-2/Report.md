### 1. 實驗目標(可參考課程投影片寫法)
- 使用 HC-SR04 超音波感測器量測前方物體的距離。
- 將量測到的距離轉換為 SG90 伺服馬達的控制角度。
- 結合超音波感測器與伺服馬達，完成依照物體距離改變伺服馬達角度的控制系統。

### 2. 設備與元件
- Arduino Uno 開發板 x 1
- HC-SR04 超音波感測器 x 1
- SG90 伺服馬達 x 1
- 麵包板 x 1
- 杜邦線若干
- USB Type-B 傳輸線 x 1
- 個人電腦（已安裝 Arduino IDE）x 1

### 3. 操作說明與成果
1. **建立伺服馬達電路**：延續 Basic Task 2-2 的 SG90 伺服馬達接線方式，將伺服馬達的電源、接地與訊號線正確連接至 Arduino。
2. **連接 HC-SR04**：將 HC-SR04 的 VCC 與 GND 分別接至 Arduino 的 5V 與 GND，並將 Trig 與 Echo 腳位接至 Arduino 的數位腳位。
3. **量測距離**：由 Arduino 送出超音波觸發訊號，讀取 Echo 回傳脈衝時間，並依據聲波往返時間計算物體距離。
4. **控制伺服馬達角度**：依照量測到的距離計算對應的伺服馬達角度，並使用 `myservo.write()` 將 SG90 旋轉到指定位置。為避免超出伺服馬達可用範圍，將角度限制在合理範圍內。
5. **實驗成果**：改變物體與 HC-SR04 之間的距離時，可觀察到 SG90 的旋轉角度會隨量測距離改變，成功完成「距離輸入 → 角度輸出」的感測器與致動器整合控制。
